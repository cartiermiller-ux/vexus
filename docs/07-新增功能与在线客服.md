## AI 在线客服

- 不再使用独立 AI 悬浮气泡；点击右下角在线客服气泡即可聊天
- `/api/ai!chat.action` 为 DeepSeek 代理接口
- 在线客服发送消息后，后端调用 DeepSeek 自动回复，写入 `t_onlinechat_message`，`USERNAME=AI_SYSTEM`
- 后台客服管理面板（所有后台页面右上角聊天图标）可查看并人工回复
- AI 配置在 `t_syspara`：
  - ai_assistant_enabled
  - deepseek_api_key
  - deepseek_base_url
  - deepseek_model
  - ai_system_prompt

## 安全

- Nginx 已对 `/api/localuser!registerTest.action` 返回 403，关闭公开测试账号注册接口。
- 建议定期轮换 DeepSeek API Key，不要发在前端或聊天中。

## 数据说明

- 腾讯公开行情为延时/收盘数据，不是交易所级实时行情。
- 美股价格为拆股调整后价格（例如 NVDA 为 10:1 拆股后）。
- 正式交易/机器人/OTC/跟单需要接入交易所或券商 API 与风控引擎，目前导航入口已接通现有页面或展示/模拟页。
