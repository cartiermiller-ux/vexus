## 三、验收中发现并修复的问题

### 3.1 行情页 Firefox 卡顿

原因：`vexus-market-hero.js` 同时使用 `MutationObserver` 和定时器，Hero 每次移动都会再次触发 observer，形成 DOM 重排循环。

修复：

- 移除 MutationObserver
- Hero 只允许定位一次
- 增加 `data-positioned` 防重入
- 保留轻量定时检查

版本：`vexus-market-hero.js?v=20261231`

### 3.2 管理后台在线客服 500

原因：`admin/online_chat_new.jsp` 引入 `include/head.jsp` 时没有定义 `basePath`，JSP 编译失败。

修复：补充：

```jsp
<% String basePath = request.getContextPath() + "/"; %>
```

修复后页面返回 200。
