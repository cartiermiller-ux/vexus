## 三、影响与注意事项

1. **admin 自己的登录谷歌验证仍可用**：后台右上角 →「谷歌验证器」（`toUpdateLoginGoogleAuth` / `googleLoginAuthBind`）可绑定。
   当前线上 `open_google_auth_code=false`（首次登录方便），**绑定后请改成 true**：
   `UPDATE jiaoyipan.t_syspara SET SVALUE='true' WHERE CODE='open_google_auth_code';`
2. **“超级谷歌验证”功能已移除**：原先用于“增删管理员/改角色/改参数”的超级验证入口全部关闭；
   相关高危操作现改为校验**当前管理员自己的**谷歌验证码（需先绑定自己的 2FA）。
   管理其他管理员 2FA 的旧页面按钮会提示“超级谷歌验证功能已移除”，属预期。
3. **noderpc 远程钱包/合约通道已彻底删除**：相关自动授权/白名单功能不再调用外部服务器；
   前端/后台相关按钮可能报错或无数据，这是安全取舍。
4. **通讯录上传、外部 SFTP 备份通道已删除**：相关接口/功能不再可用。
5. **重建提醒**：源码与 `target/classes` 都已清理；若从其它备份重新导入原始源码/原始 dump，
   后门会重新出现。**只使用本包内已清理的文件**；`web3_project` 已移出包，不要再用。
6. 法律与合规：虚拟货币交易所在中国大陆属非法金融活动；境外运营需牌照、AML/KYC 与法律评估。
   本次仅做技术层面的后门清除，不构成合规意见。
